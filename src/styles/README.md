# src/styles

## Purpose

Defines global styling foundations and design token usage.

## What belongs here

- Global CSS entry points.
- Theme tokens, spacing, typography, and utility styles.
- Base visual constraints shared by all features.

## What should not be placed here

- Component-specific CSS tightly coupled to one feature.
- Runtime logic or data handling.

## Relationship with the project

This folder establishes visual consistency for UI, layout, and 3D overlay components.
